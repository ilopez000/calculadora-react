# 🧮 Calculadora en React con Supabase

Una calculadora moderna, elegante y responsiva construida con **React**, **Vite** y conectada a **Supabase** para persistencia en la nube.

---

## ✨ Características

- 🔢 **Operaciones básicas**: Suma (`+`), resta (`−`), multiplicación (`×`), división (`÷`).
- 🔬 **Funciones científicas**:
  - **Raíz cuadrada (`√x`)**: Calcula la raíz cuadrada del número actual (con validación de números negativos).
  - **Logaritmo decimal (`log`)**: Logaritmo en base 10 ($\log_{10}$).
  - **Logaritmo natural (`ln`)**: Logaritmo en base $e$ ($\ln$).
  - **Potencia al cuadrado (`x²`)**: Eleva el valor actual al cuadrado.
- 🔄 **Operaciones adicionales**: Porcentaje (`%`), cambio de signo (`±`), borrado rápido (`⌫`) y borrado total (`C` / `AC`).
- ☁️ **Sincronización en la nube con Supabase**:
  - Historial de cálculos sincronizado y persistido automáticamente en PostgreSQL vía Supabase.
  - Indicador visual en tiempo real de conexión a Supabase (`Supabase` / `Local`).
  - Modo seguro con fallback automático a memoria local si no hay conexión o falta la clave.
- ⌨️ **Soporte completo de teclado**:
  - Números: `0` - `9`
  - Operadores: `+`, `-`, `*`, `/`, `%`
  - Científicas: `R` (`√`), `L` (`log`), `N` (`ln`), `S` (`x²`)
  - Calcular: `Enter` o `=`
  - Borrar: `Backspace` (un dígito) y `Esc` / `c` (limpiar todo)
  - Decimal: `.` o `,`
- 🕒 **Historial de operaciones**: Panel desplegable para revisar cálculos previos y cargarlos con un solo clic.
- 📋 **Copiar al portapapeles**: Haz clic sobre el número en pantalla para copiarlo directamente.
- 🔊 **Efecto de sonido opcional**: Sonido sutil al presionar teclas (activable/desactivable desde la barra superior).
- 🎨 **Diseño en colores claros**: Estilo moderno, limpio y de alto contraste con elevación suave.

## ⚡ Conexión con Supabase

1. **Crear la tabla en tu proyecto de Supabase**:
   Copia y ejecuta el contenido del archivo [`supabase_schema.sql`](file:///c:/Users/ignac/Desktop/calculadora/supabase_schema.sql) en el **SQL Editor** de tu panel de Supabase:
   ```sql
   create table if not exists public.calculations (
     id bigint generated by default as identity primary key,
     expression text not null,
     result text not null,
     created_at timestamp with time zone default timezone('utc'::text, now()) not null
   );

   alter table public.calculations enable row level security;

   create policy "Permitir lectura publica" on public.calculations for select to anon, authenticated using (true);
   create policy "Permitir insercion publica" on public.calculations for insert to anon, authenticated with check (true);
   create policy "Permitir borrado publico" on public.calculations for delete to anon, authenticated using (true);
   ```

2. **Configurar tu clave API**:
   En el panel de tu proyecto en Supabase ve a **Project Settings > API** y copia la **Project API key `anon` `public`**.
   Luego, pégala en tu archivo local `.env`:
   ```env
   VITE_SUPABASE_URL=https://ibjstqsquxfwouiuuhji.supabase.co
   VITE_SUPABASE_ANON_KEY=tu_clave_anonima_aqui
   ```

## 🚀 Cómo iniciar el proyecto

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Iniciar el servidor de desarrollo**:
   ```bash
   npm run dev
   ```

3. Abre el enlace local indicado en la consola (por defecto: `http://localhost:5173`).

## 🛠️ Comandos disponibles

- `npm run dev`: Inicia el entorno local de desarrollo con Hot Module Replacement (HMR).
- `npm run build`: Genera la versión de producción optimizada en la carpeta `dist`.
- `npm run lint`: Ejecuta el linter (Oxlint) para verificar la calidad del código.
